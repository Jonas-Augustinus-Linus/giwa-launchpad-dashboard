Token specification candidate

Purpose: a transparent, valueless GIWA Sepolia demonstration asset for testing protocol plumbing. It is not a sale, investment, meme-coin promotion, governance promise, or exchange-listing signal.

Proposed minimal behavior

  • Standard ERC-20 interface and events, fixed decimals, and an immutable maximum supply.
  • One constructor mint to a disclosed testnet address or a capped role that is permanently renounced after deterministic test distribution; choose one only after threat-model review.
  • No transfer tax, reflection, rebasing, anti-sell rule, hidden mint, blacklist, proxy upgrade, arbitrary seizure, misleading ticker, or impersonation of GIWA/Upbit/Dunamu.
  • Explicit chain guard for 91342 in deployment verification; source and constructor arguments must be reproducible and explorer-verified.

Required tests before any deployment proposal

  • Supply conservation and cap invariants; transfer/allowance edge cases; zero-address behavior.
  • Role lifecycle and impossibility of post-finalization minting or privileged transfer changes.
  • Fuzz/property tests, static analysis, compiler pin, dependency license/SBOM, reproducible bytecode, and independent review.
  • UI and documentation tests that continually label the asset testnet-only and valueless.
