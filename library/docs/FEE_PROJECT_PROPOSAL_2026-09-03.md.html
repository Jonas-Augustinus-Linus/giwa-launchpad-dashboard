GIWA 초기 유동성·fee 프로젝트 제안

2026-09-04 업데이트: "GIWA 전용 DEX를 급히 포크하지 않는다"는 부분적으로 유지된다 — v3 core는 venue 사업이 아니라 런처의 불변·owner-포기 풀 계층으로만 포크한다. fee ladder에 rung 1 "정액 생성 수수료(S3) — GO-with-conditions(Filing B + 서면의견)"가 추가되고 rung 4는 "휴면 스위치 포함 부재"로 읽는다. 상위 결정: FEE_CAPTURE_DECISION_2026-09-04.md.

기준일: 2026-09-03 KST 상태: research only / no signing / no deployment / no token sale / no liquidity provision

기술·사업·규제 리서치이며 법률·세무·투자 자문이 아니다. 실제 유료 기능은 코드, 운영 주체, 이용자 국가와 fee flow를 기준으로 별도 서면 의견과 필요한 신고를 거친다.

결정

GIWA 전용 DEX를 급히 포크하지 않는다. GIWA를 첫 adapter로 쓰는 Pool Passport / Liquidity Launch OS를 만든다. 이 제품은 새 체인이 열릴 때마다 공식 인프라, token·pool 권한, 초기 유동성 약정과 fee recipient를 검증하고, 실행 기능은 신고·허가와 역할을 갖춘 파트너 adapter가 담당하게 한다.

왜 이 포지션인가

GIWA 공식 문서는 공개 mainnet과 GIWA Wallet을 아직 개발 중으로 표시하고, 공개 GIWA Sepolia는 chain ID 91342와 ETH gas를 쓴다. GASOK Phase 3도 8~9월 testnet 지표와 private-mainnet을 목표로 하며, 참여는 Upbit 거래지원과 무관하다.

  • GIWA 연결 문서
  • GASOK 공식 페이지

그 사이 GIWATER, Joseon.fun, Ammora와 bonding-curve 구현이 이미 보여서 “첫 스왑”은 지속 가능한 해자가 아니다. 공개 권한·코드·asset·fee·LP 회수권을 한 화면과 API로 검증하는 계층이 더 비어 있다.

초기 유동성 playbook

  1. Canonical asset: issuer-backed quote asset과 bridge가 확인되기 전 mock token을 USDC 또는 실자산으로 부르지 않는다.
  2. Real capital: creator·treasury·공개 파트너가 자기자본을 약정한다. 고객 자금 모집은 하지 않는다.
  3. Fair discovery: 선착순·내부자 우선 구조 대신 공개 batch 방식의 가격발견을 설계한다. 실제 모집·배분·체결은 법률 검토를 통과한 파트너가 담당한다.
  4. POL and lock: 팀 자기자본의 LP NFT 회수권을 multisig·timelock·공개 lock에 둔다.
  5. Quality incentive: raw volume이 아니라 time-weighted depth, uptime, spread와 잔존성을 보상한다.
  6. No manipulation: wash trading, 자기거래 rebate, volume mining, 가격방어·상장 보장, 숨은 mint·tax·LP 회수를 금지한다.
  7. Cross-chain isolation: canonical bridge 전에는 같은 ticker라도 체인별 별도 자산과 재고로 취급한다.

fee ladder

단계 fee 판정 원칙
1 고정 service fee GO 후보 원화 월 구독, API tier, 고정 리포트, 공개 sponsor
2 own-account LP fee AMBER 팀 자기자본의 실제 LP 지분만; 손실한도·서면의견 필요
3 interface/router fee RED/HOLD 한국 대상 기능별 VASP 판단과 필요한 신고·파트너 이후
4 자체 AMM protocol fee RED/HOLD audit, governance, liquidity, 법률·공시 gate 이후
5 token transfer tax NO-GO 0으로 유지; buy/sell 차등·동적 고율·수익분배 금지

network gas, LP fee, protocol fee, interface fee, service fee를 한데 묶어 “거래세”로 표시하지 않는다. 체결 전 사용자 비용과 recipient가 일치해야 한다. canonical Uniswap을 유치하더라도 protocol fee가 자동으로 우리 treasury에 오지 않는다.

한국 출시 금지선

한국 법은 가상자산 매매·교환뿐 아니라 중개·알선·대행 영업도 VASP 범위에 포함한다. 비수탁이라는 이유만으로 fee-bearing UI/router가 자동 면제되지 않는다. own-account 일반 이용자에 유리한 판례도 AMM LP에 대한 직접 safe harbor는 아니다.

  • 대법원 2024도10710

서면 의견과 필요한 신고 전에는 다음을 열지 않는다.

  • 한국 이용자 대상 fee-bearing swap/router/referral
  • 외부 LP 자금 모집·운용·고객별 정산
  • launch success fee, IDO allocation, customer vesting
  • managed LP vault, solver/MEV spread
  • fee-share·revenue-share·buyback token
  • 관계자 순환거래, volume 부양, 가격·원금·상장 보장
