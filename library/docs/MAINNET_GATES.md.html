Public-mainnet decision gates

All gates default to UNKNOWN / blocked. Evidence must be refreshed when GIWA publishes a public-mainnet release; this file does not authorize launch.

  • Official public mainnet chain ID, genesis/config, RPC, explorer, bridge, finality, upgrade and incident documentation are published and independently reproducible.
  • Current node release and supported client path are pinned; archival/snapshot guidance is not contradictory; required RPC namespaces are least-privilege.
  • Sequencer, backup operation, fault-proof permission model, Security Council, upgrade keys, pauses, withdrawals, and emergency procedures are disclosed enough for a threat model.
  • Canonical ETH/stablecoin paths, bridge trust, oracle support, failure/staleness behavior, and usable liquidity are evidenced—not inferred from testnet.
  • Token and DEX contracts pass reproducible builds, unit/invariant/fuzz tests, static analysis, independent audit, deployment rehearsal, source verification, and admin-role review.
  • Multisig, timelock, monitoring, on-call ownership, incident response, upgrade/rollback policy, disclosures, and legal review are complete.
  • Market design avoids deceptive supply, fake volume, wash trading, hidden allocations, listing implications, and unsafe public solicitation.
  • A named human explicitly approves the exact revision, chain, addresses, parameters, roles, funding, liquidity limits, and launch window.
