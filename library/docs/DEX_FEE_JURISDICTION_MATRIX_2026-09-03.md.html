기준일: 2026-09-03 KST
상태: research only / no revenue activation

Decision

오스트리아는 확정 1위가 아니라 EU pre-clearance의 첫 후보입니다. 호주는 창업자가 실제 운영하는 국가일 때 AUSTRAC·ASIC·세무를 모두 예산화해 선택하고, 독일은 시장·인력 실익이 평균 약 30%의 결합 법인부담을 상쇄할 때 오스트리아와 병행 비교합니다. 미국은 custody, order routing, settlement, leverage, PFOF와 revenue token을 제거한 제한형 self-custodial UI만 주별 검토 뒤 후순위로 엽니다.

United States SEC 직원견해는 §15 한정·비구속; FinCEN/CFTC/OFAC/주법 별도 연방 C-corp 21% + 주세·분배 제한 UI의 후순위 시장

Revenue ladder

  1. 거래량·route·자산선택과 무관한 fixed B2B development/security/data fee
  2. 현지 의견과 회계정책 뒤 분리된 team own-capital LP
  3. 필요한 등록·인가 뒤 neutral interface 또는 protocol fee
  4. managed third-party vault와 fee-share/transfer-tax/buyback token은 제외

Hard stops

  • actor, order-flow, admin-key와 fee-recipient diagram 없는 공식 UI
  • 오스트리아·독일에서 무인가 EU-facing router 또는 특정 venue rebate
  • 호주에서 AUSTRAC 46A/50A/50B/50C·ASIC 금융상품 분석 없는 fee UI
  • 미국에서 custody, order taking/routing, execution, leverage 또는 전국 무차단 공개
  • 법인 등기지만 바꾸고 실제 경영·key·계약·인력을 다른 국가에 두는 구조
  • 2027 호주 DAF 또는 미국 계류 법안을 현행 safe harbour로 사용하는 구조

Before any revenue

  • 창업자 개인 세무거주와 실제 high-level decision 장소
  • 법인별 contract/UI/router/LP/treasury 역할
  • quote → calldata → signature → broadcast sequence
  • token/LP right별 금융상품 분류
  • 국가별 registration/licence·sanctions·geoblock 의견
  • invoice, payer/customer, local-currency FMV와 fee-wallet ledger
