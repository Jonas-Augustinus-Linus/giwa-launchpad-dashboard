GIWA × GABOJA 통합 의사결정 메모

2026-09-03 업데이트: 이 문서는 2026-08-25의 launch-lab 가설을 보존한다. 최신 조사에서는 GIWA Sepolia에 복수 swap·launchpad 경쟁과 성공한 V3형 test swap이 확인되어 일반 DEX를 1순위에서 내렸다. 현재 우선안은 chain-agnostic Pool Passport / Liquidity Launch OS이며, Uniswap GIWA 준비와 빗썸 신규 체인 주장은 모두 공식 근거 미확인이다. 최신 결정은 FEE_PROJECT_PROPOSAL_2026-09-03.md와 전체 보고서를 따른다.

기준일: 2026-08-25 KST 연구 상태: research only / no signing / no deployment / no domain purchase 가칭: 가보자 / GABOJA — A trust-first token launch lab for GIWA

결론

준비는 지금 시작하는 것이 맞다. 실자산 출시는 아직 아니다.

GIWA Sepolia는 살아 있는 OP Stack EVM 테스트넷이고 공식 ERC-20 개발·검증 경로와 실제 제3자 curve·AMM 배포가 있어 Pump.fun형 제품을 로컬과 테스트넷에서 검증할 기술 조건은 있다. 반면 공개 mainnet, GIWA Wallet, canonical DEX·quote asset·생산 유동성, 충분히 설명된 보안 거버넌스가 아직 없으므로 permissionless 실자산 onboarding은 차단한다.

결정 판정 범위
별도 준비 저장소 GO 근거 원장, read-only probe, 사양, 게이트

gaboja.fun 구매 HOLD 실시간 checkout·상표·handle 재확인 전 금지

왜 GABOJA인가

가보자는 한국식 추진력을 살리면서 가즈아, 떡상, 불장보다 가격상승 약속이 약하다. 영문 GABOJA도 음절 단위로 읽기 쉽고 “만들고 검증하고 함께 가보자”로 확장할 수 있다.

2026-08-25 05:43 KST authoritative .fun registry와 public RDAP bootstrap에서 gaboja.fun은 domain object가 없는 응답이었다. 이는 등록권·상표권·가격·결제 성공이 아니며 예약하지 않았다. gazua.fun은 등록 상태였다.

항상 다음 문구를 붙인다.

Independent project. Not affiliated with or endorsed by GIWA, Dunamu, or Upbit.

제품: Pump.fun 복제가 아니라 신뢰 우선 런치 랩

creator attest → metadata moderation → standardized fixed-supply token
    → virtual-reserve curve → atomic one-time graduation
    → canonical AMM → retention and abuse monitoring

핵심 설계는 다음과 같다.

  • hidden mint, transfer tax, blacklist, anti-sell, arbitrary seizure, proxy 금지
  • 초기 testnet fee와 creator reward 0
  • real reserve, sold supply, fee recipient, admin, destination pool 전면 공개
  • Dojang Verified Address, Verified Code, up.id를 서로 다른 badge로 표시
  • badge는 수익·안전·GIWA endorsement가 아니라는 고정 설명
  • graduation은 실제 quote reserve를 원자적으로 옮기는 단 한 번의 상태전이
  • 이름·ticker·이미지·링크·댓글·라이브 콘텐츠 moderation과 이의제기 로그
  • raw address·transaction·X engagement를 사람·수요·품질로 표시하지 않음

4개 언어권 공개 담론

직접 X timeline은 비로그인 조사에서 제한됐고 미러도 완전하지 않았다. 아래는 국적별 여론조사가 아니라 한국어·영어·중국어·일본어 공개 담론 표본이다.

우선시장 현재 narrative 실행 메시지 금지 메시지
한국어 업비트 유통력, 한국 빌더, wallet·밈코인 앱 기대 신뢰 표식·소비자 UX·실제 retention Upbit 상장·공식 launchpad 암시
영어 OP Stack enterprise와 early-user farming이 병존 open-source spec·audit·builder docs 미확정 airdrop·native GIWA token
중국어 faucet·bridge·UP.ID task 확산이 빠름 정확한 task와 scam warning 보상·자금조달·본토 채택 과장
일본어 testnet·전용 지갑·no-token의 신중한 가이드 안전한 학습·verification 대규모 현지 열기 가정

초기 go-to-market은 한국어 builder/consumer 실험을 1순위, 영어 audit·developer 문서를 2순위, 중국어 task/scam 안내와 일본어 safety guide를 동시에 준비하는 순서가 맞다.

연말이 뜨거울 수 있는 조건

8~9월 GASOK 제품화·private-mainnet, 10월 KBW Demo Day, GIWA Wallet 계획과 Optimism의 파트너 홍보는 실제 촉매다. 다만 다음 관찰이 있어야 연말 Bull 시나리오로 전환한다.

  1. 공식 public-mainnet config, RPC, explorer와 bridge 공개
  2. 일반 사용 가능한 GIWA Wallet build
  3. canonical quote asset·stablecoin·DEX·oracle 주소
  4. source-verified·감사된 GASOK flagship 앱
  5. 신규 wallet이 7일·30일 뒤에도 반복 사용되는 cohort
  6. 실제 reserve를 동반한 graduation과 졸업 후 pool 잔존
  7. Security Council, bug bounty, incident response와 upgrade 권한 공개

이 중 핵심 1~3이 없으면 builder 관심은 있어도 대중 유동성 출시는 늦춘다. X 좋아요나 explorer 누적 트랜잭션은 승격 조건이 아니다.

세무: DEX가 과세국을 고르지 않는다

오스트리아·호주·미국·독일·프랑스·캐나다 비교의 첫 결론은 동일하다. 개인 거주지, 시민권, 법인 등록·실질관리, 팀의 실제 업무, 고정사업장·현지 사업활동, 고객 소재지와 조세조약이 먼저다.

국가 순수 개인 투자 선별 플랫폼 사업 선별
오스트리아 신자산 일반 27.5%, 적격 crypto swap 즉시 과세 아님 법인 23%, 실질관리지·사업분류 중요
호주 swap 처분, 적격 개인 12개월 현행 50% CGT 할인 가능 법인 25%/30%, GST 검토
미국 swap 처분, 장기 0/15/20%, 단기 보통세율, NIIT·주세 가능 C법인 연방 21% + 주세·ECI·시민권 복잡성
독일 진정한 개인 보유 1년 초과 시 제23조 밖 가능 영업이면 장기보유 규칙 불가, 법인 총부담 평균 약 30%
프랑스 비전문 개인 PFU 30%, 적격 swap 이연 가능 법인 25%, 전문활동·VAT 별도
캐나다 swap 처분, 자본이면 현재 이득 1/2 포함, 사업이면 전액 연방 15% 또는 적격 CCPC 9% + 지방세·GST/HST

개인 장기보유만 보면 독일이 강할 수 있고, 잦은 스왑에는 오스트리아·프랑스가 현금흐름상 편할 수 있다. 이것을 GABOJA 법인 순위로 전환하면 안 된다. 실제 플랫폼은 creator reward, referral, curve·graduation·AMM fee, treasury와 간접세가 핵심이기 때문이다.

메인넷 수익화 전에 체류일·시민권, 팀 국가, 법인 의사결정, 고객 대상국, 수수료 수령자, 지갑 소유자, 투자·급여·배당 계획을 확정하고 관련 국가 전문가에게 공동 검토를 맡긴다.

실행 순서

Phase A — 지금, 로컬 only

  • fixed-supply LaunchToken과 factory 사양 확정
  • curve 수학 notebook/spec, rounding·solvency property 정의
  • graduation state machine과 canonical AMM interface 확정
  • Foundry unit/invariant/fuzz, static analysis와 reproducible build 구성
  • wallet·fee·creator·treasury 소유자 및 세무 이벤트 schema 구성
  • 한국어·영어·중국어·일본어 testnet/no-value/no-reward 문구 준비

Phase B — 별도 승인 후 GIWA Sepolia

  • 정확한 commit·constructor·role·deployer·종료일 승인
  • 가치 없는 token과 0-fee curve 제한 배포
  • Blockscout full source verification
  • invite-only usability, moderation drill, failure/reorg·RPC degradation test
  • wallet funnel과 7일·30일 retention 측정

Phase C — public mainnet 후보 심사

  • 새 threat model과 독립 audit
  • 법인·세무·규제·이용약관·privacy review
  • multisig/timelock, monitor, incident response, pause·exit 공개
  • canonical asset·liquidity와 launch budget 승인
  • exact chain·addresses·parameters·fee recipients·revision을 사람이 명시 승인

지금 만들어진 것과 만들어지지 않은 것

구현됨: 별도 git 저장소, 두 insane-research 세션, 113개 소스 레코드, 결정론적 주장 검증, read-only RPC allowlist·chain-ID fail-close probe, 생태계 JSON, 제품·토큰·DEX 사양, 브랜드와 mainnet gate.

미구현: Solidity, signer, deployment, faucet automation, frontend, indexer, moderation backend, 법인·도메인, 감사, 원격 저장소. 이 구분을 유지한다.

최종 권고

GABOJA는 지금 만들 가치가 있다. 다만 우위는 “남들보다 먼저 코인을 파는 것”이 아니라, GIWA가 public mainnet과 wallet을 열 때 이미 검증된 표준 컨트랙트·신뢰 UX·다국어 안전문구· 세무 원장을 갖고 있는 것이다. 다음 구현은 로컬-only contract prototype이며 testnet 배포와 실자산 출시는 각각 별도의 인간 승인 게이트로 남긴다.
