Safety and evidence boundaries

What this repository may do

  • Read public GIWA Sepolia chain metadata, block headers, sync state, and bytecode presence.
  • Catalogue official documentation, provider statements, and third-party testnet experiments with explicit provenance and observed dates.
  • Specify local contract behavior, tests, threat models, and launch gates without compiling, deploying, funding, signing, trading, or advertising.

What it must not do without a new explicit decision

  • Add or accept a private key, mnemonic, wallet connector, signer, relayer, bundler write path, faucet automation, or transaction broadcast method.
  • Deploy a token or DEX, create a pool, seed liquidity, open trading, set a market price, or invite users to buy an asset—even on testnet.
  • Treat explorer transactions or addresses as unique people, active users, adoption, TVL, or economic demand.
  • Call a project official because it runs on GIWA, entered GASOK, mentions Upbit, or uses Dojang.
  • imply that GASOK, GIWA, Dunamu, or Upbit creates a listing path.

Classification

Label Meaning
official GIWA-controlled documentation, software, or deployed protocol evidence
provider_reported A named external provider claims or documents support
third_party Independently built application or experiment; no implied endorsement
planned Future intent only; cannot be used as an available dependency
unknown Evidence is missing, conflicting, or too weak

RPC liveness proves only that an endpoint answered at an observed time. Contract bytecode proves only that code existed at an address—not ownership, safety, correctness, liquidity, or continued operation.
