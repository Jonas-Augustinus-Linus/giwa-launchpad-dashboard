한 문장 결론

지금 합법적으로 우리 것인 수수료는 고정 B2B 요금뿐이고, 메인넷 이후 열 수 있는 유일한 변동 수수료는 런처의 정액 생성 수수료(법령해석·서면의견 조건부)다. 네 제품이 60–70 %를 공유하는 실행 엔진을 한 번 만들고, 불변·무권한 v3 풀 계층과 락커 런처를 Sepolia에 fee = 0으로 올려 두며, 텔레그램 봇·per-trade 수수료·자기자본 LP는 각 관측 신호 전에는 열지 않는다.
