결론

지금 또 하나의 일반 스왑이나 Pump.fun형 런치패드를 만드는 것은 1순위가 아니다. GIWA Sepolia에는 이미 GIWATER, Joseon.fun, Ammora와 여러 제3자 AMM 실험이 있고, 2026-09-02에는 V3형 Factory·Router·Position Manager와 성공한 테스트 스왑까지 관찰됐다. 하지만 공개 메인넷, canonical Uniswap, issuer-backed quote asset, 감사된 실유동성은 아직 확인되지 않는다. (src_101, src_112, src_117, src_118, src_119, src_121; clm_201, clm_208, clm_209, clm_210)

최근 “프로젝트 발표”는 8월 24일~9월 2일의 프로젝트별 Phase 3 자기발표 물결에 가깝다. 비공식 GIWA.eco는 43개 중 29개를 selected로 표시하지만 공식 GASOK 페이지에는 팀명 roster가 없고, 공식 규칙은 5개 트랙별 최대 3팀이다. 따라서 29개를 공식 최종 선정팀으로 부르면 안 된다. Phase 3는 8~9월 제품화·private-mainnet 단계이고 공개 Demo Day는 10월의 미래 일정이다. (src_104, src_114, src_115; clm_204, clm_205, clm_206, clm_227)

권고 프로젝트

1순위는 GIWA를 첫 adapter로 삼는 chain-agnostic Pool Passport / Liquidity Launch OS다.

  • token·pool의 배포 bytecode와 source verification
  • mint·freeze·blacklist·tax·proxy·upgrade·admin 권한
  • fee recipient, treasury, vesting, LP lock·withdraw 권한
  • 멀티시그·timelock 상태와 변경 알림
  • Dojang attestation의 발행자·schema·시점 표시
  • “검증됨”과 “안전함/공식임”을 분리한 위험 API
  • chain·asset·bridge·LP commitment와 fee recipient의 evidence gate

초기 매출은 원화 B2B 월 구독 + 고정 API tier + 고정 검증·모니터링 리포트 fee로 설계한다. 주문 생성, route 선택, 지갑 서명, 자산 보관, 거래 추천, 거래량 비례 수수료는 제외한다. 이는 이미 crowded한 DEX/launchpad 시장과 차별화하면서 한국 VASP 경계에서 상대적으로 방어 가능한 출발점이다. 적법성을 보증하는 판단은 아니며 유료 출시 전 서면 법률검토가 필요하다. (src_108, src_114, src_130, src_132, src_133, src_143; clm_217, clm_218, clm_222, clm_224)

Uniswap·빗썸 체인 신호

  • Uniswap: GIWA를 준비 중이라는 공식 근거는 없다. 공식 배포·API 목록과 최신 governance 표면에 GIWA·91342 또는 배포 제안이 없다. 다만 Uniswap의 일반 전략은 새 자산이 있는 체인과 liquidity bootstrapping 도구로 확장한다고 하므로, GIWA public mainnet·canonical asset·감사된 liquidity가 나온 뒤 canonical v3 제안을 준비할 여지는 있다. (src_121, src_122, src_125, src_126, src_145, src_146; clm_229, clm_230)
  • 빗썸: 2026년 신규 L1/L2 주장은 현재 공식 공개 근거로 확인되지 않는다. 공식 GitHub, 채용·사업 페이지에는 거래소·지갑·블록체인 운영 신호만 있고 chain ID, RPC, node repo, 일정이 없다. 검색되는 Bithumb Chain은 2019년 Bithumb Global의 별도 과거 계획이다. (src_147~src_150; clm_231)

Uniswap 판정

  • v3: EVM 기술상 가능하고 core change date가 지나 GPL 조건으로 독립 검토할 수 있다. canonical 지위와 Uniswap 앱 탑재는 DAO/UAC와 Labs의 별도 절차다.
  • v4: 주요 core 파일은 2027-06-15 전 production use를 제한하는 BUSL이므로 Additional Use Grant나 별도 허가 없이 상용 포크를 권고하지 않는다.
  • 어느 버전이든 네트워크 gas는 우리 dapp 매출이 아니다. 우리가 받을 수 있는 것은 명시적 interface/service fee, 독립 프로토콜 fee, 또는 우리 자금의 LP fee뿐이다. 한국 이용자의 거래를 반복 연결하며 건별 fee를 받는 구조는 VASP 고위험이다. (src_122, src_123, src_124, src_128, src_132, src_141, src_142; clm_211~clm_215, clm_218)
