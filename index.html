공식 코드 저장소 ↗

OPENZEPPELIN / GIWA · RH

내 지갑으로 고정 공급 토큰

ERC-20 + Burnable 코드를 바로 불러옵니다. 이름·심볼을 정하고 컴파일하면 10억 토큰 전량을 연결 지갑으로 배포합니다.

03 / BUILD

실제 코드를 빌드하세요.

solc 0.8.30 · OpenZeppelin 5.4.0

LAUNCHTOKEN / V1 COMPONENT

고정 공급 토큰

현재 v1 사양의 ERC-20 + Burnable 구현을 컴파일합니다. 직접 배포 경로는 초기 공급 전량을 연결 지갑으로 보냅니다. Pons 경로는 Pons 자체 토큰을 생성하므로 이 컴파일이 필요하지 않습니다.

  • 추가 발행 · 관리자 · 업그레이드 없음
  • 전량 수취 지갑 명시 · 전송 세금 없음
  • 이름·심볼이 달라도 런타임 바이트코드는 동일

첫 빌드 때 컴파일러 약 9.6MB를 내려받습니다. 컴파일과 입력 내용은 브라우저 안에서 처리합니다.

빌드 산출물

대기 중

브라우저에서 컴파일 후 소스·ABI·바이트코드와 재현용 compiler input을 받을 수 있습니다.

토큰 구현 / 컴파일 가능팩토리 · 커브 / 설계만 있음풀 · 영구 잠금 / 설계만 있음지갑 실행 / 아래에서 검토

직접 토큰 배포는 ERC-20만 생성합니다. 거래 커브까지 만들려면 Pons V2 템플릿을 선택하세요. Pons 소스·ABI는 위에서 따로 받을 수 있습니다.

잔액 미조회

이번 실행에 필요한 ETH

초기 매수 금액은 위 공개 초기 매수 예산을 사용합니다. 직접 LP 공급 예산과 여유 예산은 이 거래에 자동으로 포함되지 않습니다.

견적·시뮬레이션을 위해 지갑 주소와 생성 입력값을 공식 RPC로 전송합니다. Pons에서 실행한 메타데이터는 온체인에 공개됩니다.

지갑을 연결하고 대상 체인을 확인하세요.

지갑에 요청할 실행 내용

Pons는 별도 운영 주체가 있는 외부 프로토콜입니다. 검증 소스와 코드 일치는 보안 감사를 뜻하지 않습니다.

지갑의 최종 확인 화면에서 직접 서명합니다. 테스트넷 ETH와 메인넷 ETH를 구분하세요.
